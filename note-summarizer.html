Before you begin

  • Choose a course, then select one note file.
  • Each note can be summarized once per student.
  • Supported files: PDF, DOCX and PPTX with selectable text. Scanned or image-only PDFs are not supported.
  • You can generate up to five summaries daily. A 30-second cooldown applies between requests.
